# Operating-Systems-1-Course-Work
This is the collection of my assignments from the OSU Operating Systems 1 Course. The code was my orignal code, but was inspired
by some rudimentary examples provided in lectures. The professor outlined functions and concepts which assisted in development of the required skills/understandings for assignment completion.


## Simple Small Shell
This code simulates a standard terminal, allowing for file navigation and operational command calls for most terminal commands. This shell also allows for multiple commands to run at once in the background, storing them in a linked list.


## Multithreading
This code is a clear display of a simple implementation of safe use of multithreading. It uses two threads which operate in tandem in access and updating a count variable, iterating till the value 10 is reached. This code adequately prevents deadlocks or other common multithreading errors.

## One-Time Pads
This assignment required us to create pipes to perform IPC between two different processes. We also created a simple encryption and decryption process to prevent something acquired raw message data.
